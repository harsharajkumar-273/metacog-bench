Evaluating Metacognition & Calibration in Frontier LLMs

MetaCog-Bench moves beyond static recall to quantify Epistemic Horizon Humility, Expected Calibration Error (ECE), and Planted Logical Flaw Auditing across frontier AI models.

🔍 Task 1: Epistemic Boundary

Probes whether a model exhibits epistemic humility when given valid vs. non-existent entities or false-presupposition queries (e.g. fictional treaties, non-existent constants).

📉 Task 2: Confidence Calibration

Measures Expected Calibration Error (ECE) and Brier Score on deceptive logic traps (Cognitive Reflection Tests) to test if stated confidence matches actual accuracy.

⚡ Task 3: Planted Error Auditing

Evaluates whether an LLM can isolate the exact step number containing a subtle planted mistake (e.g. division by zero, sign flip) in 5-step derivations.

🚀 Quickstart Installation

Install the MetaCog-Bench package locally and run evaluations against any live LLM API:

git clone https://github.com/harsharajkumar-273/metacog-bench.git
cd metacog-bench
pip install -e .

# Execute evaluation harness via CLI
python run_benchmark.py --provider gemini --api-key YOUR_GEMINI_KEY
